Ultron

A private, single-user automation agent that manages email triage, calendar, and a personal finance ledger — entirely on its owner's own computer.

What Ultron is

Ultron is a personal automation assistant developed and operated by a single individual for their own account. It is not a public application and processes no third-party personal data. It runs locally using self-hosted automation software and an on-device language model.

What it does

  • Email triage — sorts incoming messages into categories (urgent, follow-up, meeting, newsletter, receipts) and prepares reply drafts that are never sent automatically.
  • Morning briefing — a daily digest of the calendar, unread mail, and free time slots, delivered to the owner's own inbox.
  • Calendar assistance — reads the calendar and, only on an explicit owner-issued command verified by strict checks, creates events.
  • Finance ledger — records bank-exported transaction files into a local database for spending summaries. It is strictly read-only and never moves money.
Privacy by design: message and event content is processed only on the owner's own machine by a locally-running language model. No content is sent to any cloud AI service, and data is never sold, shared, or used for advertising. See the Privacy Policy for details.
