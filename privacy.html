Privacy Policy

Ultron — a personal, single-user automation agent

Overview

Ultron is a personal automation agent developed, operated, and used exclusively by its developer — a single individual — for their own Google Account. It is not distributed to the public, has no other users, and processes no third-party personal data whatsoever.

The developer and sole user is the same person, and can be contacted at miroperafr@gmail.com regarding any aspect of this policy.

What data Ultron accesses

Ultron requests read access to the developer's own Gmail and Google Calendar, plus the narrow write abilities listed below. Specifically:

  • Gmail — read: message headers and body text of incoming mail, used to sort messages into categories (urgent, follow-up, meeting, newsletter, receipts), to prepare reply drafts, and to compile a daily briefing.
  • Gmail — labels: the ability to apply existing labels to messages as part of that sorting.
  • Gmail — drafts: the ability to create draft replies. Drafts are never sent automatically; the owner reviews and sends every draft personally.
  • Gmail — send (own address only): Ultron emails status notifications to the owner's own address only (e.g., daily briefing and confirmations of owner-issued calendar commands).
  • Google Calendar — read: event times and titles, used to find free slots, prepare the briefing, and check for scheduling conflicts.
  • Google Calendar — create: events are created only in response to an explicit, strictly-formatted command issued by the owner from their own email address, and only after automated conflict checks pass. Every creation is confirmed to the owner by email.

Ultron also maintains a local finance ledger: bank transaction export files (CSV) uploaded by the owner are parsed and stored in an SQLite database on the developer's own computer. This data involves no Google services and never leaves the machine.

How data is used, processed, and stored

Local-first processing: all message and event content is analyzed on the developer's own computer by a language model running locally in a self-hosted container. No email content, calendar content, or financial data is sent to any cloud AI service.

Derived data (category assignments, short summaries, prepared drafts) and the local finance ledger are stored on the developer's own disk, in private storage not accessible to anyone else. No data is sold, rented, shared with third parties, or used for advertising of any kind. Google's limited use requirements are respected: data is used only to operate the features described above.

Data retention and deletion

Stored data (classification records, the finance ledger, drafts in Gmail) persists locally until the developer deletes it. Deleting stored files removes them permanently, as they exist only on the developer's machine. The owner can revoke Ultron's access to Google data at any time via Google Account settings (Third-party access), which immediately and permanently ends all API access.

Changes and contact

If this policy changes, the updated version will be published at this same address. For any question about Ultron or its data practices, contact the developer at miroperafr@gmail.com.
