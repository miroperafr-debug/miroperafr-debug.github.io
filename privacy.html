Ultron — Privacy Policy

Ultron is a personal automation agent operated solely by its developer (contact: miroperafr@gmail.com). It is not distributed to the public.

Data accessed

  • Gmail: reading message headers and bodies (read scope), applying labels, and creating drafts. Ultron never sends email on behalf of the user without the user's own explicit approval.
  • Google Calendar: reading events and, only upon a user-approved command, creating events.

How data is used and stored

All data is processed on the developer's own computer. Classifications, summaries, and drafts are produced by a local language model; no message or event content is sent to any cloud AI service. Transaction records are stored in a local SQLite database on the developer's machine. No data is sold, shared with third parties, or used for advertising.

Data retention and deletion

Data persists locally until the developer deletes it. Revoking access in Google Account settings immediately ends all access.
